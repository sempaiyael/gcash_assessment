# Success Criteria

How the hiring team will evaluate this project. Use to prioritize work and self-assess before submission.

## Evaluation Dimensions (Inferred from Email)

| Dimension | What They're Looking For | Weight |
|-----------|-------------------------|--------|
| **Technical Skill** | Can you build ML models, clean data, evaluate properly? | High |
| **Creativity** | Do you go beyond obvious approaches? | High |
| **Communication** | Can you explain to non-technical stakeholders? | High |
| **Business Acumen** | Do you understand the business problem? | Medium |
| **Rigor** | Is your work reproducible and well-documented? | Medium |
| **Self-Awareness** | Do you know limitations and future directions? | Low-Medium |

## Pass vs Exceptional

### Minimum Viable (Pass)
- [ ] All 4 EDA questions answered
- [ ] Hit movie metric defined with justification
- [ ] Prediction model built with novel algorithm
- [ ] Source paper cited for novel algorithm
- [ ] Executive slides for studio management
- [ ] Clean code in Git repo with README
- [ ] All deliverables emailed to hiring team

### Exceptional (Stand Out)
- Everything in Pass, plus:
- [ ] Bonus recommender system built and evaluated
- [ ] Second presentation for streaming service
- [ ] Novel insights beyond what's asked (e.g., genre trends, director patterns)
- [ ] Interpretability analysis (why the model makes specific predictions)
- [ ] Business recommendations (what to invest in, what to avoid)
- [ ] Discussion of limitations and future work
- [ ] Professional, polished presentation design

## Self-Assessment Before Submission

Ask yourself:
1. **Would I present this to an actual studio executive?** If no, polish more.
2. **Can someone clone my repo and run everything?** If no, fix README and requirements.
3. **Do I know why my model works (or doesn't)?** If no, add interpretability analysis.
4. **Have I answered "so what?" for every finding?** If no, add business framing.
5. **Am I proud of this work?** If no, identify what's missing and fix it.

## What Sets Candidates Apart

Based on typical DS hiring:
- **Average**: Answers the questions, code works, basic slides
- **Good**: Clean code, good visualizations, clear narrative
- **Exceptional**: Business insights, interpretability, self-awareness, polished delivery

The email explicitly asks for "creativity and technical rigor" — they want someone who goes beyond the minimum.
