# TabNet Paper

**Title**: TabNet: Attentive Interpretable Tabular Learning
**Authors**: Arik, S. O., Pfister, T.
**Venue**: AAAI 2021
**arXiv**: 1908.07442

## Key Contributions

- Sequential attention mechanism for instance-wise feature selection
- Sparsemax activation for sparse feature masks
- Self-supervised pre-training via masked feature prediction
- Interpretability through visualizable attention masks
